  📸 HESHENG 按钮工厂 - 图片文件夹说明
═══════════════════════════════════════════════════════════════

本文件夹包含网站所需的所有图片资源

📁 文件夹结构：
├── products/     (产品图片 - 6张)
├── process/      (工艺流程 - 4张)
├── hero/         (首屏背景 - 1张)
├── about/        (工厂介绍 - 1张)
└── partners/     (认证标志 - 3张)

─────────────────────────────────────────────────────────────

📦 products/ (产品图片)
   尺寸：800×800px (正方形)
   格式：PNG 或 JPG
   大小：每张 ≤200KB

   ✓ p1-horn.png       仿牛角纽扣 (棕色/米色)
   ✓ p2-pearl.png      珠光白纽扣 (白色/光泽)
   ✓ p3-shell.png      贝壳纹理纽扣 (自然纹理)
   ✓ p4-laser.png      激光雕刻纽扣 (可含Logo)
   ✓ p5-matte.png      哑光复古纽扣 (深色)
   ✓ p6-tortoise.png   玳瑁纽扣 (深棕斑纹)

   拍摄建议：
   - 使用微距模式，45°俯拍
   - 柔和光照，展示纽扣质感
   - 纯色背景，纽扣居中
   - 占画面60-70%

─────────────────────────────────────────────────────────────

🏭 process/ (生产工艺)
   尺寸：1200×800px (3:2 横向)
   格式：WebP 或 JPG
   大小：每张 ≤300KB

   ✓ step1-mix.webp    原料调配 (液态树脂/调色)
   ✓ step2-cast.webp   离心浇铸 (机器设备)
   ✓ step3-cut.webp    车削成型 (自动车床)
   ✓ step4-polish.webp 抛光检验 (成品分拣)

   拍摄建议：
   - 真实工厂场景
   - 展示机器和工序细节
   - 充足工业照明
   - 可包含工人操作

─────────────────────────────────────────────────────────────

🌟 hero/ (首屏背景)
   尺寸：1920×1080px (16:9 宽屏)
   格式：WebP 或 JPG
   大小：≤500KB

   ✓ hero-bg.webp      网站首屏大背景

   内容建议：
   方案A: 工厂厂房外景
   方案B: 生产线全景
   方案C: 高端纽扣特写（深色背景）

   要求：
   - 深色调为主（便于白字显示）
   - 中心留白（用于放标题）
   - 低调奢华，营造高级感

─────────────────────────────────────────────────────────────

🏢 about/ (工厂介绍)
   尺寸：1200×800px (3:2 横向)
   格式：WebP 或 JPG
   大小：≤300KB

   ✓ lab-main.webp     实验室/办公区

   内容建议：
   - 质检实验室（仪器设备）
   - 样品展示墙
   - 设计办公区
   - 会议室/接待区

   要求：
   - 干净整洁的环境
   - 体现专业性
   - 可调为黑白增加质感

─────────────────────────────────────────────────────────────

🏆 partners/ (认证标志 - 可选)
   尺寸：400×200px (2:1)
   格式：SVG > PNG > JPG
   大小：每张 ≤50KB

   ○ grs-logo.svg      GRS环保认证
   ○ oeko-logo.svg     OEKO-TEX认证
   ○ higg-logo.jpg     Higg指数认证

   注意：
   - 必须使用官方正版Logo
   - 优先使用透明背景
   - 避免侵权问题

🔧 如何替换图片：

1. 准备您的图片，按上述要求调整尺寸
2. 重命名为对应文件名（包括扩展名）
3. 直接拖入对应文件夹，覆盖现有文件
4. 浏览器刷新查看效果 (Ctrl+Shift+R 强制刷新)
